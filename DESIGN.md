# Guffin Design System

Guffin is a film diary with a cinematic interface with a dark and a light theme. The design
contract lives in [`design/rules/`](design/rules), split by topic: the visual tokens, the
interaction contract, the components, and the motion engine that every page, surface and hover
answers to. It is written for contributors and for AI agents that generate or review UI in this
repository: follow it literally, and when it is silent, extend the system instead of working
around it.

Section numbers are kept across the files, so a reference such as "section 3.7" or "§4" still
points to the same text.
